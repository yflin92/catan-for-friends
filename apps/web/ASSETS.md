# Web client assets and licences

Every visual in `apps/web` is original work drawn in code for Hexlands (requirements C1, V40):

| Asset | Where | Source | Licence |
|---|---|---|---|
| Terrain colours, terrain pictograms, number tokens, harbor markers | `src/board/art.ts`, `src/board/Board.tsx`, `src/board/board.css` | Original SVG shapes drawn in code | Project licence |
| Settlement, city, road and robber shapes; seat colours, labels and road dash patterns | `src/board/art.ts`, `src/board/Board.tsx` | Original SVG shapes drawn in code | Project licence |
| Fonts | `system-ui` stack | The viewer's operating-system fonts; nothing is bundled | n/a |

No third-party images, icon sets, fonts or logos are bundled. Names are generic (Hexlands; hills, forest, pasture, fields,
mountains, desert; brick, lumber, wool, grain, ore). Add a row here for any third-party asset before it is committed.
